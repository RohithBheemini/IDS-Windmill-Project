5. Data Hygiene, Leakage Prevention & Physics Boundaries
Rule 1: Post-Trip Status Code Purge (No Cheating)
Raw logs contain status_type_id (0=Normal, 4=Downtime). Models that include status codes achieve 99.9% artificial accuracy because downtime is recorded after trip. Status codes were strictly purged to enforce genuine pre-trip early detection.
Rule 2: Zero Synthetic Data (Veto on SMOTE)
Synthetic oversampling creates physically impossible combinations (e.g. 2,000 kW power at 0 m/s wind). The dataset strictly retains 100% genuine sensor telemetry, preserving thermodynamic and Betz aerodynamic validity.
