2. Taking the Project Into Your Own System (Setup Guide)
Step 1: Clone Repository 
# Clone repository via Git
git clone https://github.com/RohithBheemini/IDS-Windmill-Project.git

# Move into root directory
cd IDS-Windmill-Project
Step 2: Install R Package Dependencies 
# Run in terminal / PowerShell once:
Rscript -e "install.packages(c('data.table',
'zoo','ranger','xgboost','pROC','lime',
'shiny','bslib','bsicons','DT','ggplot2',
'scales','rmarkdown','knitr'),
repos='https://cloud.r-project.org')"
3. Running the Application & Workflows (main.R)
Target Action CLI Command Description / Output
Launch Dashboard Rscript main.R --app Opens interactive Shiny UI at http://127.0.0.1:3838
Run Terminal Demo Rscript main.R --demo Simulates Event 72 breakdown, 14-day lead time & XAI output
Full Demo + App Rscript main.R Executes live CLI demo and automatically launches browser app
Retrain Models Rscript main.R --train Re-fits GLM, Random Forest, and XGBoost models (0.67s training)
Re-clean Telemetry Rscript main.R --clean Re-engineers physics features (ΔT, 6h rolling, gear slip)
